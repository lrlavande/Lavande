# Lavande
Une petite appli qui me servira a track mon humeur, mon budget, mes dépenses pour récolter pleins de data sur moi et analyser ça plus tard. L'objectif, est de mettre en lien l'humeur, les dépenses, la météo et autres pour analyser avec des chiffres les réels comportements des utilisateurs. Et m'apprendre à mettre de côté aussi :p
